# Problem Statement + Stakeholder Analysis

## Problem Statement

ปัจจุบันวิชา SIT0013 เช็คชื่อเข้าเรียนด้วยวิธีเรียกชื่อทีละคน ซึ่งมีปัญหาดังนี้:

- เสียเวลาในคาบเรียน — เรียกชื่อนักศึกษา ~33 คนทุกคาบ
- เก็บ/ค้นข้อมูลย้อนหลังยาก
- ไม่มีหลักฐานเชิงเวลาว่านักศึกษามาถึงเวลาใดจริง

เป้าหมาย: ลดเวลาที่เสียไปกับการเช็คชื่อ, ได้ข้อมูลดิจิทัลค้นย้อนหลังได้,
ลดโอกาสเช็คชื่อแทนกัน (proxy attendance)

ขอบเขต: จำกัดเฉพาะวิชา SIT0013 (SEC N01) ที่อาจารย์สมคิดสอนเท่านั้น

## Stakeholder Analysis

| Stakeholder | บทบาท | ความต้องการหลัก |
|---|---|---|
| อาจารย์ผู้สอน | ผู้ดูแลระบบ / สร้าง session | เช็คชื่อเร็ว, ดูรายงานง่าย |
| นักศึกษา (~33 คน) | ผู้ใช้สแกน | สแกนง่าย เร็ว ไม่ต้องมีแอปเฉพาะ |
| มหาวิทยาลัย/หลักสูตร | ผู้รับผลข้อมูล | ข้อมูลถูกต้อง สอดคล้อง PDPA |
